# Bot 模式产品目录

这是 Bot 模式现在怎么用、对象怎么分、每条规则用户能看到什么的总目录。实现细节、接口字段和历史方案留在文末的设计笔记里。

## 现在会怎样 / 还不会怎样

已经按验收标准实现、用户现在可以用的，写在 01–09。下面这些还不是当前产品：

- **草稿，未实现。** 输入区再瘦一圈、定时任务改成拨动开关、群成员管理离开主聊天区、用户气泡用 Bot 主题色、用量行补发送钟点。规格还在 `draft`，见 [10 状态](10-status.md)。
- **规格已批准，尚未标成已实现。** 活动栏按主人隔离、发布验收、一部分群规模界面、群目标、群内原位批准、群子任务接力、例行任务完整生命周期、软件执行的验收收口、插话必须马上出现、默认 Super Bot 的派工汇总。意图写在对应章的「还没收口」里，不要当成已经验收通过。

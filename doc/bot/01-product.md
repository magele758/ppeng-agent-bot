# 01 产品是什么

Bot 模式是普通对话里那个 Agent 的长期形态。用户不按每一轮去选「任务模式」或「编排引擎」。Bot 自己决定直接回答，还是动手做，以及用哪一种已经授权的执行方式。

普通对话仍在。Bot 模式不取代它，也不把每一条普通会话都变成 Bot。

规格：`bots`、`bot-autonomous-execution-coverage`、`bot-entry-simplification`。

## 和普通对话的差别

| | 普通对话 | Bot |
|--|----------|-----|
| 寿命 | 一条会话，用完可以另开 | 一只 Bot 一条固定主对话，一直续在同一条上 |
| 身份 | 当前选中的 Agent | 有名字、脸、自己的模型、自己的权限和工具范围 |
| 记忆 | 用户记忆、这场对话的上下文 | 再加这只 Bot 自己的记忆；看不到另一只 Bot 的私有记忆 |
| 工作 | 这一轮里的工具调用 | 可以同时有多件目标、子任务、定时任务和群里的发言 |
| 列表 | 会话列表 | Bot 列表里是 Bot 自己的主对话；它派生的子任务出现在普通会话列表 |

用户在 Lab 里用顶部的对话 / Bot 切换。两条列表分开。群聊出现在 Bot 这条列表里，但一眼能和单只 Bot 区分开。

## 对象

这些词在后面各章意思固定，不要混用。

| 对象 | 是什么 | 不是什么 |
|------|--------|----------|
| Bot | 名册里的一只长期助手。有名字、脸、固定主对话、模型、权限、工具和技能范围 | 不是一条临时会话，也不是群 |
| 主对话 | 这只 Bot 和用户一直续聊的那一条。压缩、停止、换模型都发生在这一条上 | `/new` 不会另开一条 |
| 子任务 | Bot 为多出来的一件工作派生的会话。有任务原文，能从普通会话列表、主对话流和详情里打开 | 不是这只 Bot 的主对话，也不出现在 Bot 侧栏和置顶里 |
| 目标 | 用户要达到的一个结果。可以排队、进行、等待、受阻、暂停、完成、失败或取消 | 一次执行结束不等于目标完成 |
| 执行 | 推进某个目标的一次尝试。有方式、证据和费用 | 不是目标本身 |
| 定时任务 | 到点、隔一段时间、只跑一次，或由外部事件叫醒的安排。有自己的工作会话 | 不占用、也不抄走主对话的历史 |
| 群 | 至少两只 Bot 的一份共享记录。有名字、成员和自己的历史 | 不是把每只 Bot 的主对话拼在一起 |
| 功能分组 | 给 Bot 归类的一组。用来在列表里收纳，也可以作为技能和共享条文的范围 | 不是团队任务，也不是群聊 |

## 用户待在哪

1. **Bot 列表。** 找一只 Bot、一个群，或从「新建」里创建 Bot、群、功能分组。
2. **主对话。** 说话、看它干活、插话、引用一条回复再发。
3. **右侧详情。** 看这只 Bot 的定时任务、文件、记忆、技能和子任务。页签直接可点，子任务不铺在顶部把下面挡住。
4. **普通会话列表。** 打开某条子任务。标题是任务原文，能看出属于哪只 Bot。
5. **设置。** 改这只 Bot 的权限、模型、技能范围，以及全局的重复检测。保存后下一轮就生效，不用重启，也不靠新增环境变量。

管理页和创建页分开。创建时只填这一次要的东西。任务分派、运行限制和群管理不堆在新建 Bot 的表单里。

## 产品原则

- **Bot 自己选做法。** 能直接答就直接答。要执行就调用已经授权的能力，并给出实际结果。做不到就说明原因，或请求用户做必要的那一步。不把「已经派出去」说成「已经做完」。
- **危险的事要人点头。** 权限放到完全放行必须再确认一次。该审批的操作不会因为换了一条子任务就自动放行。
- **各看各的。** 一只 Bot 读不到另一只的私有记忆。一个用户看不到另一个用户挂在同一只 Bot 上的目标和定时任务。
- **失败要看得见。** 连接断了就说暂时不能确认，并留下上次更新时间。外部操作结果不明就停住，等人核对，不自动再做一遍。
- **界面文案有中文和英文。** 新增说法两边一起加。语言存在浏览器里，不靠环境变量。

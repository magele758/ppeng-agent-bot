# 投资人演示 PPT

[打开 PowerPoint 文件](output/Bot-Investor-Deck.pptx)

18 页，前 12 页为约 9 分钟主讲，后 6 页为问答附录。第 2 页切到 Bot 现场操作，第 3 页切到真实运行历史，第 4 页返回商业叙事。第 12 页结束主讲。每页 PowerPoint 演讲者备注均包含时间、讲法与证据边界。

参考：[9 分钟原讲稿](../11-investor-demo.md) · [完整功能说明](../00-functional-guide.md) · [资源需求说明](resources.md)。

资源配置按 6 个月、7 人全职等效投入设计。现有员工可兼任，不代表必须新增 7 名员工。42 人月为从首月至第六月全额投入的计算，实际按角色到岗时间折算。20 次访谈、10 家设计伙伴等均为建议目标，不是现有业务数据。融资金额待岗位全成本、实际报价和可用资金核定。

演示前需要准备真实报告、来源、历史记录和备用录屏。PPT 已留切换位置，不内嵌未提供的产品截图或虚构运行记录。字体使用 Hiragino Sans GB，Windows 上建议先检查中文字体替换后的排版。

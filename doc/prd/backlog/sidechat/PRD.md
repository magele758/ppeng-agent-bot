## 1. 用户想完成什么

读 Bot 的长回答时，我遇到一个似懂非懂的词，希望当场把它问明白，再接着读。几天后重看这段话，我还想知道当时困惑在哪里、后来是怎么想通的。

例如，读到「模型把前文每个 token 的键和值保存在 KV cache 中」时，我圈出 **KV cache**，问「它究竟存了什么？」。听完解释，我继续问「为什么不把 Query 也存进去？」。这两轮留在同一处批注里。后面读到 **首字延迟**，我可以再起一条。下次回到这篇回答，两处讨论都能从各自的原文重新打开。

**成功体验**：从发现疑问到开始输入，只需选中、点「侧聊」；关上侧栏，眼睛能立即找到刚读的那句。侧聊保留原回答的语境，主对话保持自己的思路。

## 2. 入口和页面结构

| 位置 | 行为 |
| --- | --- |
| 已完成的助手回答正文 | 鼠标选词或选段后，在选区附近显示「侧聊」。保留系统复制。手机支持长按选词。 |
| 回答的操作区 | 增加「就这条回答侧聊」，适合整条扩写，也提供键盘入口。现有「引用回复」继续面向主输入框。 |
| 聊天页右侧工具栏 | 增加「侧聊」视图和本会话已保存的条数，与活动、上下文、产物等共用右栏位置。打开时主会话仍为当前会话。关闭后恢复之前的侧栏状态。 |
| 侧聊列表 | 默认当前主会话，可切换到「全部批注」跨会话查找。当前会话列表显示短引文、首问标题和更新时间。默认最近更新优先，原文上的编号按创建顺序稳定。右上「＋」打开当前回答的侧聊草稿，可再选一段缩小范围。 |
| 侧聊详情 | 顶部保留原文摘录和「回到原文」，下方是独立历史与输入框。桌面同时展示紧凑列表与详情，列表较长时独立滚动。窄屏以全高抽屉在列表和详情间切换。 |

## 3. 从第一次提问到下次重读

1. **选中**　一段选区只能属于同一条已完成的助手回答。支持正文、列表、行内代码与代码块里的可选文本。流式生成中的回答完成后开放入口；阅读其他已完成回答时仍可开侧聊。
2. **起草**　点「侧聊」立即打开右栏，显示选中文本并聚焦侧聊输入框。用户可自行提问，或用「解释一下」填入可编辑问题。未发送的草稿在切换侧聊时保留，空草稿不增加计数、不留下原文标记。
3. **对话**　首次发送即创建侧聊并留下标记；沿用源回答的 Bot 或普通 Session 的 Agent。首问携带原文摘录、所在回答及触发该回答的用户问题（如有），后续加上本条侧聊历史。过长时优先保留摘录及邻近段落。侧聊输入、生成状态、停止和重试均归属该条侧聊。切走后生成可继续。
4. **继续阅读**　收起侧栏恢复主区阅读锚点、展开状态和输入草稿。侧聊中的问答不写入主时间线，不进入主轮模型上下文，也不把主会话顶到最新。用户仍可独立向主会话发消息。
5. **重访**　从原文点标记打开对应历史；从列表点引文，载入含源消息的历史，滚到原句并短暂强调。只有主动点「回到原文」才主动滚动主区。刷新、重新登录后仍可重访已保存讨论。
6. **同处再问**　点已有标记默认续聊；从选区或侧栏显式新增可建立另一条。同处多条时聚合为一个带数量的入口，点开先选讨论，避免堆叠标记。

## 4. 视觉与交互取舍

- **正文优先。** 默认收起侧聊。桌面开启后复用右栏的宽度，正文与右栏分别滚动。打开引起换行时，以选区所在行相对视口的位置为基准补偿滚动。聚焦侧聊输入框时避免浏览器把主区带到底部。
- **像在页边做批注。** 已讨论的文字用淡色底纹、下划线和小编号；活动引文加深，并在右栏重复同一编号。颜色只辅助识别。原文很长时在右栏预览首段，详情可读完整快照。
- **两处输入有清楚的归属。** 主输入框标为「发送到主对话」，右栏标为「在这条侧聊中追问」。首次打开才自动聚焦，消息流更新不抢焦点。Esc 收起侧聊，焦点返回入口。
- **可访问。** 标记可 Tab 聚焦，Enter 打开；读屏名称包含引文和侧聊数。窄屏返回关闭抽屉后恢复阅读位置。跟随 Lab 字号、皮肤和语言，所有正式界面文案配中英文。

## 5. 归属、保存与异常

| 情形 | 产品约定 |
| --- | --- |
| Bot 与普通 Session | 以用户和主 Session 为归属，一个 Bot 的不同会话拥有各自列表。沿用源回答者身份；首版覆盖一对一 Bot 和普通 Session 的助手文本。首版支持跨会话检索个人批注；群聊、多级侧聊和共享知识库留待后续评审。 |
| 保存与定位 | 服务端保存侧聊 ID、主会话和源消息稳定 ID、回复方、选区文本与前后文、在可见文本中的偏移、编号、标题、时间、消息及生成状态。以原文快照支持重读。遇到重复词需验证上下文及位置。 |
| 来源更新或移除 | 能唯一匹配才精准跳转。只能找到消息时定位到消息并提示「原文已有变化」。源消息已移除时保留摘录与讨论，停用跳转；主会话删除则按同一删除策略处理其侧聊。沿用主会话的访问权限。 |
| 异常与重试 | 保存失败保留本地草稿并提示重试。响应失败保留已发问题，引导在当前侧聊重试；网络重连或重复点击不重复建聊、不重复追加同一问题。 |
| 首版管理 | 新增、按会话列出、跨会话浏览和关键词搜索、切换、续聊、双向定位。列表标题默认来自首个问题。重命名、归档和导出留待后续。 |

## 6. 批注格式与跨会话索引

**一处原文可以挂多条讨论，一条讨论可以有多轮问答。** 每条讨论有全局稳定的侧聊 ID。视觉稿里的「01」「02」是会话内的展示编号。即使两条批注引用同一个词，也各自保留原文、时间和追问历史。

| 记录 | 保存什么 | 用来做什么 |
| --- | --- | --- |
| 原文锚点 | 锚点 ID、源会话与消息 ID、整条或选区、摘录快照、相邻文本、可见文本中的起止位置及文本规范化版本 | 点回同一处原文；同一处的多条讨论可复用锚点 |
| 批注讨论 | 侧聊 ID、锚点 ID、所有者、源 Bot 或 Agent、标题、创建和更新时间 | 稳定链接、权限过滤、当前会话列表和全局目录 |
| 批注消息 | 消息 ID、侧聊 ID、顺序、角色、正文、时间 | 展示完整历史；搜索命中某次追问时直接定位那一轮 |

**两个入口，共用同一份数据。** 侧栏默认「本会话」。切到「全部批注」即可浏览自己在所有仍有权访问的会话中留下的批注，可按 Bot、源会话或时间缩小范围。摘录旁提供「找其他会话中的相同摘录」，以当前选词查找其他会话里摘录文本相同的批注，排除当前会话。两个会话碰巧出现同一字符串并不足以认定它们在讨论同一概念，由读者根据上下文判断。

**索引与结果。** 对摘录、首问标题、每一轮问题和回答建立可重建的全文索引。索引项带侧聊 ID、命中字段及可选的消息 ID。搜索时先限制所有者和可见会话，再匹配及排序。精确摘录优先，其次标题、问答正文，同级按最近更新。一条侧聊只展示一个结果，可展开其余命中。短词（如「缓存」「KV」）需支持字面匹配；关键词搜索不依赖模型或向量服务。索引写入与消息保存保持一致，清除或撤权后结果、计数和预览同步消失。

**示例。** 阅读《部署排查》时选中「KV cache」，点击「找其他会话中的相同摘录」，右侧列出《模型推理入门》中的「它究竟缓存了什么？」。先在右栏预览旧讨论，主阅读位置保持不动。主动点「打开来源」才切到旧会话，定位原句并打开对应侧聊；返回后恢复《部署排查》的阅读位置和草稿。若只记得回答里的「键和值」，也可以在「全部批注」搜索，结果显示命中回答的片段。

**实现边界。** 可沿用仓库现有跨会话消息搜索的可见会话过滤和结果摘要交互，新增面向批注的索引。原始记录是数据来源，索引可从记录重建。首版提供字面搜索和同摘录发现；以后需要处理「键值缓存」与「KV cache」之类的不同叫法时，可加概念别名或语义检索，保留每条原始讨论的独立身份。

## 7. 验收场景

| 场景 | 通过条件 |
| --- | --- |
| 半页处选词并连续问两次 | 同一侧聊出现两组问答和一个稳定标记；主历史、主输入草稿及主轮上下文保持原样。 |
| 同一回答里建两条 | 两条可在右栏独立切换，输入草稿、流式输出、停止或重试均归属正确。点各自标记打开各自的讨论。 |
| 同一个词出现两次 | 针对第二处建聊，刷新后跳回第二处。同一处另建讨论后出现聚合入口。打不开唯一位置时给出降级提示。 |
| 从旧消息回看 | 从列表点「回到原文」可载入较早的源消息并强调选区。侧栏普通开关不会把阅读位置吸到底部。 |
| 会话和持久化 | 同一 Bot 的 A、B 两个会话列表独立。在另一浏览器用同一账号登录 A 后，可看到已保存的讨论与摘录。 |
| 狭窄视口和键盘 | 手机抽屉可从列表进详情再回原文。键盘可从整条回复入口完成提问并返回；主、侧输入目标可辨。 |
| 服务失败 | 首次提交后断网再重试，恢复后只出现一条侧聊与一份用户问题。 |
| 跨会话重访 | A、B 各有一条「KV cache」批注；在 B 查相同摘录可预览 A，主动打开来源后定位 A 的原句，返回恢复 B 的草稿与阅读位置。 |
| 搜索后续问答 | 只有某条侧聊第三轮回答包含「缓存」时，搜索这两个字仍命中。该侧聊出现一次，可定位到第三轮。 |
| 权限与删除 | 会话被删除或访问权撤销后，全局结果、相同摘录入口、计数和旧链接均不泄露其批注内容。 |

## 8. 这次评什么

视觉稿从《部署排查》的「KV cache」批注开始。点「找其他会话中的相同摘录」，预览 11 月 12 日《模型推理入门》里的旧问答。点「打开来源，定位原句」进入旧会话，再点「返回《部署排查》原处」。试着先在当前侧聊输入半句话，返回后草稿和阅读位置都应保留。

也可以从「全部批注」搜索「Query」，直接预览答疑的对应轮次；支持按来源会话筛选。点正文已有标记、选词新建、输入追问和刷新重访仍可体验。两份会话和示例回复均为本地演示数据。服务端索引、跨设备同步、访问权限及真实模型生成留到实现阶段验证。

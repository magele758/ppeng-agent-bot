理解大模型的推理过程

我模型是怎样一个字一个字生成回答的？为什么要用缓存？
通用助手10:42

从读完问题，到写下答案

可以把生成过程分成两个阶段。模型先一次读入你的问题，算出第一个输出 token。随后，每生成一个新 token，就用已经读过的内容来预测下一个。

为什么不必每次都从头读？

模型把前文每个 token 的键和值保存在 KV cache 中。下一步生成时，它直接读取这些结果，只为新加入的 token 做相应的计算。

你看到的首字延迟，包含模型处理输入并产出第一个 token 所花的时间。后续文字陆续出现，对应的就是逐步解码。

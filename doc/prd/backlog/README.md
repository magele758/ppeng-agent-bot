# 未来待开发

这一块只回答「还不能当现成功能用的东西」。它和 [现在已有的功能](../current/README.md)、[已经开发的功能](../shipped/index.md) 分开，不把那边的说明再写一遍。

## 未实现和已取消的验收规格

未实现的规格，以及已取消的规格，都看 [from-acceptance.md](from-acceptance.md)。

该文件由 `node scripts/prd/build-catalog.mjs` 生成，不要手改。验收规格改过之后重新跑这条命令。不要在这里抄规格里的需求正文。

已取消的规格出现在生成清单里，只说明需求取消了。它不是待做功能，也不要写成现在能用。

## 还没有验收规格的方向

见 [direction.md](direction.md)。

方向不是当前产品。每一条都写明还不是承诺，也不等于已经排期。某条方向一旦有了验收规格，就从方向里删掉，只留在生成清单里。

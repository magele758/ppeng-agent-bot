# Bot 设置与生效范围

创建 Bot 只需名称；用途为可选，职责和外观在「可选资料与外观」展开。创建完成进入该 Bot 对话。
聊天侧栏和 Bots 管理页共用设置面板：基本设置、能力与权限、自动化、记录。
模型、权限和步数上限在基本设置；工具和统一技能选择在能力与权限；连接向导按需展开。

| 设置 | 生效时机与范围 |
| --- | --- |
| 名称、职责、说明 | 保存即更新资料显示；身份提示在下次执行采用 |
| 模型、工具 | 此 Bot 固定对话下一执行步骤；已发出的模型请求不重发 |
| 权限档 | 当前固定对话后续步骤；bypass 仍要求确认 |
| 步数上限、内核与装配 | 下次执行；不改变当前执行预算或内核 |
| Bot 技能范围 | 此 Bot 及其任务后续技能选择与加载；已有子任务的模型/会话权限保持创建时快照 |
| 技能路由与加载策略 | 全局下一执行步骤；搜索与加载实时读取 |
| 交互卡片与已安装领域 | 全局下一执行步骤；停用后新工具调用被拒绝，可用列表同步变化 |
| 外观 | 保存成功立即显示 |

技能页保留同一 Bot 内切换设置页签的使用范围与共享草稿，失败保留输入供重试。
旧 `allowedSkills` 名称白名单在读取时被忠实映射到 ID 选择，只有明确保存才清除固定对话上的旧名单；并发修改触发版本冲突，已有子任务的会话白名单不改写。

全局入口为「设置 → 工具」：

- `PATCH /api/skills/settings`：`disclosureMode`、`routingMode`（legacy/lexical/hybrid）、`topK`（1–50）、`strictLoad`、`fusion`。未保存的路由字段分别回退原有环境值。hybrid 除排序候选外还可加入关键词匹配。
- `PATCH /api/runtime-capabilities`：`a2uiEnabled`、`domains`（仅接受当前安装目录中存在的 ID）。分别回退 `RAW_AGENT_A2UI_ENABLED` 与原有领域自动探测；保存后以持久化值为准。
- API 返回 `effective.applyAt`；面板分别显示下一步骤或下次执行。失败不会显示为已生效。`/api/config/effective` 同时读取已保存能力与实际领域目录。

没有新增环境开关。端口、鉴权、上游连接等进程级配置仍有启动边界；新安装领域代码仍需部署。已安装目录按 runtime 实例隔离，另一个实例启动不会改变当前实例的工具归属；启停配置仍共享并持久化。领域启用只开放已安装能力，连接凭证与工具权限仍单独校验。已发生的外部副作用不会因关闭能力而撤销。

验证包括两个真实执行内核的中途工具增删、同一 runtime 中能力启停及执行拒绝、技能严格加载、API 版本冲突，以及浏览器保存/失败重试/草稿保留与创建流程。

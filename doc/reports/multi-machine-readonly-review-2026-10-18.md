## 修复

- 群消息与任务在同一事务接收；无效 mentions、附件、操作或幂等冲突不留下可运行任务。
- 私聊派单核对实时会话与人工唤醒来源，Bot 转发或 Routine 的 user 角色文本不能充当人工授权。
- 排队期间撤销配置时，相关任务明确失败，其他机器和巡检继续；SSH 探查返回时再次核对连接与授权，丢弃旧别名的结果。
- 关闭期间等待调度退出，probe/status/inspect 回调不再写入已关闭数据库或启动新任务。
- Authorization、Cookie、多词密码与 URL 凭据完整脱敏；远程回执先校验结构与完成证据。
- 群内查询包含进展时间、结果和错误；回复去重按主体、任务和查询隔离。
- UI 丢弃过期轮询的成功与失败结果，同步已保存的巡检状态并保留未保存机器字段；群选择尚未保存时禁止误操作巡检。

# 第三刀回退准备（含已持久化自动会话）

适用 v1.1「回退总规则」+ 拆分稿 §2.6 + v2.3 §6.3 / §8.4 / §12。
本文件只准备检查项与演练步骤，不实施回退，不改生产开关。

## 回退目标

关闭**获准的 Swarm 宿主入口**，立即阻止新的交接准入。普通单会话交接保持第二刀承诺，飞轮不得经共用 Swarm 间接打开交接，#516 口径不因回退而放宽或收窄成「用关闭掩盖已放宽的成功映射」（本刀禁止放宽，回退也不得留下放宽）。

## 必须覆盖的会话面

| 面 | 回退后期望 | 风险 |
| --- | --- | --- |
| 新的独立 Swarm 运行 | 不得再进入轨迹交接 | 入口关闭不彻底，或默认落入 `independent_swarm` |
| 已在途的 Swarm 交接运行 | 受控收尾或取消；不得直接在旧路径重放 | 重放导致重复副作用或重复扣额 |
| 结果未知的在途调用 | 失败关闭；保留预算占用；不得自动当成功 | 把未知当未发生，赚额度 |
| 等待裁决 / 已持久化 deadline 的挂起 | 保留记录；迟到恢复不得重启任务 | 回退程序读不懂记录却执行 |
| 飞轮 `implement` 经共用执行器 | 仍不得自动启用交接 | 关独立入口时误开飞轮，或关飞轮时误伤独立入口 |
| **已经持久化自动策略的普通会话**（`auto_policy` / 第二刀写入的显式开启） | **继续按第二刀策略运行**；停止写新 Swarm 交接记录 ≠ 关闭这些会话的开启面 | 回退脚本误清 enablement、把新会话当旧会话关、或为「临时继续 Swarm」改普通会话默认 |
| 显式关闭的普通会话 | 保持关 | 回退时误开 |
| 旧会话默认关（第二刀契约） | 保持关 | 回退改默认 |

第二刀合入前，持久化字段的最终形状可能变化。本预备只锁行为，不锁表结构。等第二刀合入后，用真实 persist 记录替换 stub 再做一次演练。

## 演练步骤（实现后；现在不要在生产跑）

1. **冻结现场**：列出运行中的 Swarm run、挂起的 `awaiting_coordinator`、未决调用预约、已持久化普通会话启用记录。不得在这一步改账本。
2. **关闭入口**（仅 Swarm 获准入）：阻止新的独立 Swarm 交接准入。不要改 `gate.ts`，不要改普通会话默认。
3. **在途处理**：对每个未决调用先停止或完成对账；`outcome` 未知 → 失败关闭并保留占用。不得重放到旧路径。
4. **迟到事件**：入口关闭后到达的 `coordinator_resumed` / 新 `refillId` 必须拒绝；不得扣父级、授额、启动调用。
5. **核对普通会话样本**：
   - 已持久化 `auto_policy` 且启用的新工作型会话：下一轮仍走交接（第二刀路径）。
   - 显式开启的旧会话：仍开启。
   - 显式关闭 / 旧会话默认关：仍关闭。
6. **核对飞轮样本**：`implement` 经 `startSwarmForRun` 仍不启用交接。
7. **核对门禁**：未验证产物、旧证据、内核 `done`、非成功终态不得变成交付成功。
8. **版本回滚限制**：只有在没有需新协议处理的活动运行，或目标版本已有兼容处理能力时，才回滚到不理解这些运行记录的程序。否则先排空或保留兼容读。

## 禁止的「临时继续」

- 绕过父级账本继续补额。
- 放宽 #516 或把 Swarm `completed` / 内核 `done` 直接当交付成功，以便「先关掉交接再上线」。
- 用改普通会话默认来补偿 Swarm 入口被关。
- 回退第三刀时连带关闭已验收的普通会话交接（那是第二刀面）。
- 回退第三刀时解除飞轮限制，或反过来为了关飞轮而关死将已验收的独立 Swarm（第四刀回退另有条款；本刀回退不应预支第四刀入口）。

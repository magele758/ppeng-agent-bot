# 第三刀回退准备（含已持久化自动会话）

适用 v1.1「回退总规则」、§4.3、§4.6、§4.7、§5.6，以及 v2.3 §6.2 末段、§6.3 期限规则、§8.4、§12。
本文件只准备检查项与演练步骤，不实施回退，不改生产代码，不打开生产 Swarm 入口。Pattern B 保持零行（含入口关闭基础原语）。不改 `gate.ts`，不改 `engine.ts`。缺失 `capabilityTiers` 保持 `enabled: false`，回退不得把它翻成默认开启。

## 回退目标

关闭**获准的 Swarm 宿主入口**，立即阻止新的交接准入。普通单会话交接保持第二刀承诺：已经持久化的 `auto_policy` / 显式开启会话继续按第二刀运行。停止写新的 Swarm 交接记录不等于关掉这些会话。飞轮不得经共用 Swarm 间接打开交接。#516 口径不因回退而放宽，也不得收窄成「用关闭掩盖已放宽的成功映射」（本刀禁止放宽，回退也不得留下放宽）。

实现阶段必须**保留**关闭获准 Swarm 宿主入口的手段（v1.1 §4.3）。本预备不在生产代码里添加该开关，也不打开该入口。

## 必须覆盖的会话面

| 面 | 回退后期望 | 风险 |
| --- | --- | --- |
| 新的独立 Swarm 运行 | 不得再进入轨迹交接 | 入口关闭不彻底，或默认落入 `independent_swarm` |
| 已在途的 Swarm 交接运行 | 受控收尾或取消；不得直接在旧路径重放 | 重放导致重复副作用或重复扣额 |
| 结果未知的在途调用 | 失败关闭；保留预算占用；不得自动重放，也不得当成成功或未发生 | 把未知当未发生而赚额度，或自动再执行 |
| 等待裁决 / 已持久化 `waitDeadline` 的挂起 | 保留且不改写；不得重放到旧路径；迟到恢复不得重启任务 | 回退程序改写记录，或读不懂仍执行 |
| 挂起的 `awaiting_coordinator`（入口已关） | 迟到 `coordinator_resumed` 或新 `refillId` 拒绝：不扣父级、不授本地额度、不启动调用。取消与超时都已满足前置时，先成功提交的事务胜出，后到忽略（v2.3 §6.3） | 迟到恢复重启任务，或两个终态事务都生效 |
| 飞轮 `implement` 经 `startSwarmForRun` / `tryCompleteImplementStep` | 仍不得自动启用交接。不改 `engine.ts`、不改 `gate.ts`。见下方 tip 事实 | 关独立入口时误开飞轮，或借回退打开交接 / 放宽 #516 去补门 |
| **已经持久化自动策略的普通会话**（`auto_policy` / 第二刀写入的显式开启） | **继续按第二刀策略运行**；停止写新 Swarm 交接记录 ≠ 关闭这些会话的开启面 | 回退脚本误清 enablement、把新会话当旧会话关、或为「临时继续 Swarm」改普通会话默认 |
| 显式关闭的普通会话 | 保持关 | 回退时误开 |
| 旧会话默认关（第二刀契约） | 保持关 | 回退改默认 |
| 缺失 `capabilityTiers` | 保持 `enabled: false`；回退不得翻成默认开启 | 把缺失层级当成默认开 |

**保留不删：** 已用预算、计划版本、未决调用、等待裁决记录、已持久化 `waitDeadline`。回退不改写这些记录，也不把它们重放到旧路径。第二刀合入前，持久化字段的最终形状可能变化。本预备只锁行为，不锁表结构，不发明 persist schema。等第二刀合入后，用真实 persist 记录替换 stub 再做一次演练。

## 演练步骤（实现后；现在不要在生产跑）

1. **冻结现场**：列出运行中的 Swarm run、挂起的 `awaiting_coordinator`、未决调用预约、已持久化普通会话启用记录、已持久化 `waitDeadline`。不得在这一步改账本，不得删改已用预算、计划版本、未决调用或等待裁决记录。
2. **关闭入口**（仅 Swarm 获准入）：阻止新的独立 Swarm 交接准入。实现必须保留可关闭获准入口的开关；本预备不在生产代码添加该开关。不要改 `gate.ts`，不要改 `engine.ts`，不要改普通会话默认，不要把缺失 `capabilityTiers` 翻成默认开启。
3. **在途调用、结果未知**：对每个未决调用先停止或完成对账；`outcome` 未知 → 失败关闭，保留占用，不得自动重放，不得在旧路径重放（v2.3 §6.2）。
4. **挂起样本 `awaiting_coordinator`**：入口关闭后到达的迟到 `coordinator_resumed` 或新 `refillId` 必须拒绝；不得扣父级、不得授予本地额度、不得启动调用。若取消与超时都已满足各自前置而竞争，以先成功提交的持久化事务为准，后到的忽略（v2.3 §6.3）。
5. **核对普通会话样本**：
   - 已持久化 `auto_policy` 且启用的新工作型会话：下一轮仍走交接（第二刀路径）。停止写新 Swarm 交接记录不等于关掉这些会话。
   - 显式开启的旧会话：仍开启。
   - 显式关闭 / 旧会话默认关：仍关闭。
   - 缺失 `capabilityTiers`：仍为 `enabled: false`，不得在回退中改为默认开启。
6. **核对飞轮样本**：`implement` 经 `startSwarmForRun` 与 `tryCompleteImplementStep` 仍不启用交接。已知 tip：`tryCompleteImplementStep` 按 Swarm 终态 `completed` / `failed` / `cancelled` 结束 implement 步，且不调用 `qualityPassed`。同文件里 `review` / `test` 分支会调用 `qualityPassed`；`research` 分支只 `completeStep`，并不调用。该门禁缺口属第四刀。第三刀回退不得通过打开交接或放宽 #516 来「修好」它，也不得改 `engine.ts` / `gate.ts`。
7. **核对门禁**：未验证产物、旧证据、内核 `done`、非成功终态不得变成交付成功。证据须绑定被验证的版本和任务范围（v2.3 §12）。
8. **版本回滚限制**：只有在没有需新协议处理的活动运行，或目标版本已有兼容处理能力时，才回滚到不理解这些运行记录的程序。否则先排空或保留兼容读。回滚程序不得改写上述保留记录。

## 第四刀交互（非行动预备说明；本预备两个入口都未打开）

一旦第四刀存在：回退第四刀必须让**已经验收的独立 Swarm 入口仍可运行**，并重新施加「飞轮不得经共用执行器自动启用交接」。回退第三刀不得打开飞轮，也不得用来预先关闭一个将来才验收的独立入口。本预备既未打开独立 Swarm 生产入口，也未打开飞轮入口（v1.1 §4.6 / §5.6）。本说明不可执行，不授权现在改生产接线。

## 禁止的「临时继续」

- 绕过父级账本继续补额。
- 放宽 #516，或把 Swarm `completed` / 内核 `done` 直接当交付成功，以便「先关掉交接再上线」。不得改 `gate.ts`。
- 用改普通会话默认来补偿 Swarm 入口被关。
- 把缺失 `capabilityTiers` 从 `enabled: false` 改成默认开启。
- 回退第三刀时连带关闭已验收的普通会话交接（那是第二刀面），包括已经持久化的 `auto_policy` / 显式开启。停止写新 Swarm 交接记录不等于关闭这些会话。
- 回退第三刀时解除飞轮限制，或为了关飞轮而关掉已经验收的独立 Swarm。
- 回退第三刀时打开飞轮，或把本次回退用来预先关闭尚未存在的、将来才验收的独立入口。
- 用打开交接或放宽 #516「修好」`tryCompleteImplementStep` 不调用 `qualityPassed` 的 tip 行为。不得改 `engine.ts`。
- Pattern B 任何实现，包括入口关闭基础原语。
- 发明 persist 表结构；第二刀合入前形状可能变化。

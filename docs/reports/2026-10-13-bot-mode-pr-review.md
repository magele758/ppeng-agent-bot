## Review 后修复

| 切片 | 修复与复验重点 |
| --- | --- |
| 连续对话 | 按最终送给模型的输入确认回执，而不是压缩前的准备事件；从原 WAL 恢复被压缩隐藏且未读的输入，保持来源关联并防止无进展循环；关闭后不再调度数据库写入 |
| 可靠任务 | 审批等待期间仍执行 deadline；公共批准与运行入口也检查过期/已停止工作；取消与恢复关闭旧执行，同时保留新接收的人类输入及来源别名；取消不能掩盖未知副作用 |
| 队列容量 | 溢出摘要与其已登记源回执不重复计数；保留旧摘要、principal 隔离和原有 429 边界 |
| Routine | unknown 取消后保留需要核对副作用的来源状态，重试及 UI 必须明确确认 |
| 群聊 UI | 空选择不再覆盖默认主持/正文 @；切群清空旧输入状态并隔离迟到响应；轮询跨页缺口重置游标，可继续回读旧页 |
| 团队 UI | 加载历史页后，已展示任务完成仍进入历史，不能从列表消失 |
| 定时 UI | 编辑时选择无预检可真正清除既有预检 |
| 软件连接 | 凭据绑定、修改已有凭据连接和探测遵循管理员权限；实际 HTTP socket 使用已校验地址并保留原 hostname 的 TLS 校验；编码后的凭据回显脱敏；不支持的 OpenAPI server override 明确拒绝；异常响应不会抛出未捕获异常 |
| 软件大结果 | 产品执行在截断前保存完整原文与真实 artifact handle，模型可搜索并分页读回超过 120k 的中段；尊重归档设置，普通 8KiB 输出不膨胀为假 handle |
| 任务上下文整合 | 派工保留追加输入捕获的上下文；恢复只退役已隐藏输入的来源事实和精确匹配的未完成 Todo，保留新输入及其他来源；压缩只保留最新摘要，隐藏最新摘要不会复活旧摘要 |
| 主线整合 | 运行时每个历史工具只注册一次；已登录普通聊天保留主线身份/namespace 内检索；匿名、Bot、Room 与其派生会话只访问当前会话；稳定引用使用索引回读，兼容原前后文接口 |

没有删除或弱化已批准验收条件。两处测试构造修正保留原断言：真实建立 agent 别名绑定，以及同一时钟下严格验证审批 TTL。模拟模型显式声明其验收场景中的 131072-token 窗口，未知真实模型仍使用可配置保守回退。
